# 了解计算机、互联网和工具的基础知识
## 电脑的基本组成部分有哪些？
电脑是非常强大的机器，可以执行各种任务，例如编写文档、玩游戏和浏览互联网。

作为一名开发人员，了解计算机的基本内部工作原理非常重要。

计算机的第一个主要部件是主板。主板承载着计算机运行所需的所有内存和接口，是计算机的主要电路板。

在电脑主板的机箱内部，你会找到CPU，即中央处理器。CPU是一个处理器，负责执行指令和进行计算。它通常被称为电脑的大脑。

CPU是一个带有芯片的小方块，可以插入主板上的CPU插槽。CPU处理器的速度以千兆赫兹（GHz）和兆赫兹（MHz）为单位。千兆赫兹等于每秒十亿次循环，兆赫兹等于每秒百万次循环。

计算机的下一个关键组件是系统的短期存储器，也称为 RAM 或随机存取存储器。RAM 是计算机 CPU 的临时存储空间。每当计算机需要快速访问数据时，它都会使用 RAM。

电脑内存越大，运行速度就越快，同时运行的程序也越多。如果内存不足，电脑运行速度就会变慢，性能上的差异也会很明显。

需要注意的是，RAM是易失性存储器。这意味着计算机关机后，数据就会丢失。因此，务必将工作保存在计算机上。

当你保存文件时，它们会被存储在硬盘上。硬盘驱动器（HDD）是一个永久存储位置，即使计算机关机，数据也会保存在这里。你所有的文件和软件都存储在这里。

硬盘由旋转的盘片和磁头组成。盘片用于存储数据，磁头则用于读取和写入盘片上的数据。硬盘速度越快，电脑启动速度越快，程序运行速度也越快。

另一种数据存储方式是固态硬盘（SSD）。SSD 是一种非易失性闪存，可以替代传统硬盘。SSD 比传统硬盘速度更快、体积更小，但传统硬盘价格更低、存储容量更大。

计算机的另一个关键组件是电源供应器（PSU）。电源供应器负责将墙壁插座的电能转换成计算机可以使用的形式，并将电能输送到主板、CPU 和计算机的其他组件。

另一个关键组件是扩展卡。这些卡插入主板，为计算机添加额外的功能。扩展卡的例子包括显卡、声卡和网卡。

视频卡，也称为图形处理单元或 GPU，负责在计算机屏幕上渲染图像。

声卡负责通过电脑扬声器播放声音。

网卡负责将计算机连接到互联网。

尽管电脑的部件远不止这些，但这些是一些你现在应该熟悉的基本部件。
## 如何有效地使用键盘、鼠标和其他指点设备？
你们中的许多人多年来一直习惯于使用键盘和鼠标进行各种活动，例如玩游戏、完成工作任务或上网。

但长期滥用这些设备可能会导致日后严重的健康问题。

在本课中，我们将介绍如何以健康的方式使用电脑的键盘和鼠标。

首先要注意鼠标的握法。在处理重要的工作任务或进行激烈的游戏时，你可能会不自觉地用力握住鼠标。然而，这会导致严重的手腕和手部问题。为了避免这种情况，你应该轻柔地握住鼠标，保持手指放松。

第二个建议是考虑使用符合人体工学的键盘和鼠标。这些工具旨在通过保持双手处于更自然的位置来减轻手腕疲劳。

虽然这些设备的价格各不相同，而且可能超出您目前的预算，但它们对您的长期健康来说是一项不错的投资。因此，您不妨开始研究一下符合人体工程学的键盘和鼠标。

另一个小技巧是保持鼠标和键盘的高度一致。你肯定不想为了使用鼠标而抬头或低头，因为长时间这样做会拉伤你的手腕和手臂肌肉。

长时间坐在电脑前工作时，你也需要注意整体姿势。弯腰驼背、手腕在键盘上处于不自然的位置都会导致长期的健康问题。因此，使用电脑时，务必保持正确的坐姿，并保持手腕处于健康自然的位置。

最后一条建议是尽可能使用键盘快捷键，以减少打字次数。有很多快捷键可用于浏览网页、操作系统导航、代码编辑器操作等等。因此，最好研究一下这些快捷键，并将它们融入到你的日常电脑使用中。

在您继续使用鼠标和键盘进行即将到来的编码项目和其他活动时，请记住这些健康提示。

## 互联网服务提供商有哪些类型？
首先，什么是互联网服务提供商（ISP）？简而言之，它是一家出售全球互联网接入服务的公司。它们分为三个不同的级别。

第一层级是巨型企业集团，它们拥有基础设施，可以独立处理大部分（如果不是全部）网络流量。

第二层级是全国性运营商，它们有时会租用第一层级网络的接入，但也能独立运营得相当不错。

第三层级是主要专注于为本地市场提供互联网服务的小公司，它们依靠大型互联网服务提供商来提供基础设施。

这些服务提供商也会提供不同类型的连接。

光纤连接依靠玻璃或塑料光纤通过光来传输数据，从而实现非常高的连接速度和数据交换。

有线连接使用与有线电视提供商相同的基础设施，这使得它们在许多地区都很容易获得。

DSL 连接使用与固定电话服务相同的基础设施。由于这种基础设施的普及，DSL 可以在有线电视网络无法覆盖的地区使用。但它的速度通常也较慢。

拨号上网也使用电话线，但需要独占连接（连接互联网时，该线路将无法用于电话通话）。这是一项年代久远的技术，现在已经很少使用了。

卫星连接利用环绕地球运行的卫星阵列，将世界各地的各种设备连接起来。最后，与之类似，5G 家庭互联网服务提供商利用基站基础设施来保持您的在线状态。

这样你就能对市面上的互联网服务提供商和互联网连接类型有一个基本的了解了！
## 有哪些安全的电脑登录方式？

你们当中许多人使用电脑已经有一段时间了。但是你们可能没有考虑过最安全或最可靠的电脑登录方式。

无论你使用的是Mac还是PC，都有很多方法可以安全地登录你的电脑。

首先，你应该确保你的电脑已设置密码保护。

Windows 用户请先打开“开始”菜单，然后选择“设置”。接着，依次点击“帐户”和“登录选项”。之后，您就可以为您的计算机设置密码了。

_注意：如果您遇到任何困难或使用的是其他版本的 Windows，请参阅微软官方文档或支持资源，以获取针对您特定版本的详细说明。_

创建密码时，请确保密码足够长且足够复杂。您可以使用字母、数字和特殊字符的组合来提高密码安全性。

`12345`选择像“1”或“2”这样简单的密码`password`并不是个好主意。这些密码很容易被猜到，也很容易被破解。

此外，不要使用包含个人信息（例如姓名、生日或地址）的密码。这些信息也很容易被黑客猜到。

创建密码时，最好同时启用双因素身份验证 (2FA)。2FA 可以提供额外的安全保障，需要第二种验证方式来确保尝试访问帐户的人确实是授权用户。

如果您是 Mac 用户，可以点击苹果菜单，然后进入系统设置。从那里您可以找到“用户与群组”，并为您的电脑设置密码。

部分Mac电脑配备了Touch ID功能，该功能通常被认为比传统密码更安全。这项功能允许您使用指纹登录电脑。

对于 Windows 用户而言，Windows Hello 功能提供了一种更安全的登录方式。它使用面部识别或指纹等生物识别方法进行身份验证，为传统的密码登录方式提供了替代方案。

完成本课后，我强烈建议您了解这些额外的安全功能，并在您的计算机上设置它们，以确保您的计算机安全无虞。

## 专业开发人员使用哪些不同类型的工具？

专业开发人员依靠各种工具来提高工作效率和代码质量。让我们来了解一下这些工具，包括那些看似显而易见的工具。

工具之首便是计算机。计算机是主要的开发环境。它可以是笨重的台式机，也可以是便携式笔记本电脑，操作系统可以是 Windows、macOS 或 Linux。

专业开发人员通常会选择处理能力快、内存大的计算机来处理资源密集型任务。

电脑之后是用于在电脑上直接编写和编辑代码的程序。那就是代码编辑器或集成开发环境（IDE）。

Visual Studio、IntelliJ IDEA、JetBrains 和 PyCharm 等 IDE 提供强大的功能，例如代码补全、调试和集成终端支持。

Visual Studio Code (VS Code) 本质上是一个代码编辑器，但它也通过其丰富的扩展库提供了这些功能。

其他代码编辑器包括 Sublime Text、Atom、Notepad++ 和 Brackets。

使用代码编辑器和集成开发环境 (IDE) 编写代码时，需要跟踪代码的更改。版本控制系统就是用来跟踪这些更改的工具。

Git是开发社区中使用最广泛的版本控制系统。

GitHub、GitLab 和 Bitbucket 等平台为您的 Git 代码仓库提供基于云的托管服务。这些平台支持与其他开发者协作，允许您在多个分支上工作，并简化代码变更的合并过程。

包管理器是另一个至关重要的工具。它们可以帮助开发者简化添加、更新和删除库及项目依赖项的过程。

常用的软件包管理器示例包括：

- 用于 JavaScript 的 NPM、Yarn 和 PNPM。
- Python 的 PIP
- PHP Composer
- Maven for Java

开发人员使用不同的工具编写代码后，会测试这些代码以确保其按预期运行。

为此，开发人员会使用 Cypress、Playwright、Selenium 等测试框架。此外，还有一些特定于编程语言的测试框架。例如：

- Jest for JavaScript
- Python 的 pytest
- JUnit for Java
- PHPUnit for PHP

你不仅需要测试代码以确保其按预期运行，还需要测试代码在最终用户眼中的显示效果。开发人员通常使用网页浏览器来实现这一点。

像Chrome、Firefox、Edge和Safari这样的现代浏览器都提供了开发者工具，用于检查HTML、CSS和JavaScript代码。此外，它们还提供调试和性能分析工具。

这些工具可以帮助开发者测试和优化其 Web 应用程序在不同浏览器上的用户体验。
# 使用文件系统
## 如何在电脑上使用文件管理应用程序？

文件管理应用程序可以帮助您轻松地在电脑上存储、整理和编辑文件。无论您使用的是 Mac 电脑还是 Windows 电脑，都有内置的应用程序可以用来整理文件。

如果你使用的是Windows电脑，默认的文件管理器是文件资源管理器。它用于浏览、搜索和管理文件和文件夹，以及执行复制、移动和删除等文件操作。

要找到文件资源管理器，您可以转到“开始”菜单或按键盘上的 Windows 徽标键。

要固定文件夹，您可以右键单击鼠标并选择“固定”。要移动文件或文件夹，您需要先选中它，然后选择“剪切”，再导航到新位置并粘贴。

如果您使用的是Mac电脑，默认的文件管理器是Finder。它提供对本地和远程文件的访问，支持文件预览，并提供各种组织功能，例如标签和智能文件夹。

要在 Mac 上打开 Finder，请转到底部的 Dock 栏，然后点击 Finder 图标。

您会注意到左侧有一个侧边栏，您最喜欢的文件夹就位于那里。

整理文件的一种方法是使用标签。要给文件或文件夹添加标签，可以在 Finder 中选择该项目，然后右键单击。您会在下拉菜单中看到“标签…”选项，您可以应用自定义颜色的标签。

要查找带标签的项目，您可以滚动到侧边栏底部并单击相应的彩色标签，或者您可以在搜索字段中按颜色名称搜索标签。

另一种整理文件的方法是使用智能文件夹。智能文件夹是根据您设置的条件（例如文件类型、日期或关键字）自动整理的文件集合。

无论你使用的是 Windows 上的文件资源管理器还是 Mac 上的 Finder，这些应用程序都提供了灵活的文件管理功能，例如标签、搜索和智能文件夹。
## Web应用程序文件命名最佳实践是什么？
当你开始构建自己的 Web 应用程序时，你需要注意文件的命名。

您应该以易于理解和维护的方式命名文件。

我们来看一些HTML文件的正确和错误文件名示例。请注意，`.html`这些示例中的文件扩展名表明这是一个HTML文件。

以下是一个错误文件名的示例：

```md
index1234.html
```

单从文件名来看，无法确定该文件的用途。它可能是产品页面、博客页面或其他任何类型的页面文件，但我们无法从文件名中得知。

以下是一个更合适的 HTML 文件命名示例：

```md
about-us.html
```

使用更具描述性的名称，例如`about-us.html`，可以清楚地了解文件的内容。

您还会注意到，这个文件名中没有空格。而是用连字符“, `-`”来分隔单词。

有时您可能会看到一个名为“.example”的文件`index.html`。这是一个特殊的文件名，用于表示网站的主页。当您访问网站时，该`index.html`文件是第一个加载的文件。

文件命名时另一个需要考虑的重要因素是特殊字符的使用。

使用特殊字符、数字和字母的混合格式可能会使人难以理解文件的内容。

以下是一个错误文件名的示例：

```md
file-1!@.html
```

这个文件名看起来过于复杂，并没有提供任何关于文件内容的信息。

因此，文件名最好只使用字母和连字符。

随着你学习的语言越来越多，你会发现这些语言在文件命名方面也有一些通用的约定。

在这种情况下，最好查阅官方文档或其他资源，以了解该语言中文件命名的最佳实践。

此外，你还会遇到需要与团队合作的情况，这时你需要遵守团队制定的文件命名规则。
## Web应用程序中文件/文件夹组织的最佳实践是什么？
在构建Web应用程序时，文件和文件夹的组织结构非常重要。这有助于保持代码的条理性和可维护性。

让我们来看一个HTML和CSS项目的示例文件夹结构：

```bash
.
├── /assets
│   ├── /images
│   │   ├── logo.png
│   │   ├── banner.jpg
│   │   └── icons.svg
│   ├── /fonts
│   │   ├── custom-font.woff
│   │   └── custom-font.woff2
├── /css
│   ├── main.css
│   ├── about.css
│   └── contact.css
├── index.html
├── about.html
├── contact.html
└── README.md
```

示例顶部有一个点，代表根目录。

根目录是文件系统中的顶级目录，是所有文件路径的起点，并包含所有其他目录和文件。目录是文件夹的另一种说法。

在根目录下，显示的第一个目录是项目`assets`文件目录。该目录`assets`指的是项​​目中使用的所有文件，例如图像、字体或其他资源。

在这个例子中，目录下有两个子目录，`assets`分别名为`images`和`fonts`。

下一个目录是`css`样式表目录，有时也称为样式表目录。这里存放着所有的 CSS 文件。

目录下方`css`是 HTML 文件。该`index.html`文件代表首页，而`about.html`和`contact.html`分别代表“关于我们”和“联系我们”页面。

最后，还有一个`README.md`文件。`README`文件通常用于提供有关项目的有用信息，例如项目的功能、使用方法以及任何其他相关细节。

该`.md`扩展名代表 Markdown，它是一种轻量级标记语言，常用于编写文档。

通过将项目组织成资源文件、CSS 文件和 HTML 文件，您可以轻松找到所需内容。这也方便其他开发者为您的项目做出贡献。
## 如何使用资源管理器/Finder 创建、移动和删除文件和文件夹？

要在 Windows 系统中使用资源管理器创建文件，您可以点击右上角的“新建”选项。这将显示您可以创建的不同文件类型的列表。

您也可以在相应的应用程序中创建文件。我们来创建一个文本文件来演示这个过程。

点击“新建”并选择文件类型后，您将在当前文件夹中看到一个带有默认名称的新文本文件。您可以根据需要重命名它。

创建文件夹的过程完全相同。点击右上角的“新建”按钮，然后选择“文件夹”选项；或者右键点击空白处，选择“新建”，再选择“文件夹”选项。您将在当前位置看到一个新的空文件夹。

您可以通过选中文件和文件夹，然后点击顶部的“重命名”选项来重命名它们。当当前文件名高亮显示时，您可以开始输入新文件名。按 Enter 键确认更改。

或者，您可以右键单击文件或文件夹，然后选择“重命名”选项，或使用快捷键 F2。输入新名称，然后按 Enter 键确认更改。

如果已将文件或文件夹以标签页形式打开，则可以通过拖放操作将其移动到另一个文件夹。

您也可以选择文件或文件夹，然后选择顶部的“剪切”选项。

然后，转到目标文件夹，点击顶部的“粘贴”按钮粘贴文件。如果您之前复制或剪切过该文件，则此按钮将处于启用状态。

您也可以右键单击空白处，然后单击粘贴图标来完成此操作。这将从其原始位置删除文件或文件夹。

要删除文件或文件夹，请单击它，然后单击顶部的垃圾桶图标。右键单击该文件或文件夹，也会找到“删除”选项。

太好了。现在我们来看看如何在 macOS 上使用 Finder 来完成这项操作。

Finder是macOS上的默认文件管理器。

要在 macOS 上创建文件，您需要打开一个可以创建所需文档类型的应用程序。目前，Finder 本身并没有内置的直接创建文件的方法。

例如，要创建一个简单的纯文本文件，您可以打开文本编辑器并保存文件。对于任何类型的文件，操作过程都完全相同。

打开文本编辑程序的方法有很多种。其中一种方法是打开启动台。然后，搜索可以创建所需文件类型的应用程序。在本例中，就是“文本编辑”。点击图标即可打开该应用程序。

进入应用后，您应该能在应用菜单中看到保存文件的选项。该菜单位于右上角，苹果菜单图标旁边。

在应用程序菜单选项中，您应该能看到保存文件的命令。该命令通常位于“文件”菜单下。

旁边会显示保存文件的快捷键。这通常出现`Command + S`在 macOS 系统中。

首次保存文件时，应该会看到一个对话框，您可以在其中输入文件名并选择保存位置。

通常情况下，文件扩展名由应用程序自动添加，但您可以在保存文件之前更改它。

## 在 Web 应用程序中，您会用到哪些常见的文件类型？

文件根据其内容和结构进行分类。文件类型决定了计算机程序如何打开和处理文件。

我们根据文件扩展名来识别文件类型。文件扩展名是文件名末尾的三到四个字母的后缀。Web 应用程序中最常见的三种文件类型是 HTML、CSS 和 JavaScript。

HTML 文件包含 Web 应用程序的结构和内容。它们具有`.html`.html 文件扩展名。

CSS 文件定义样式。它们有`.css`文件扩展名。

JavaScript 文件则添加了更高级的功能和交互性。它们有 .js`.js`文件扩展名。

在开发Web应用程序时，您还需要添加图像。以下是一些最常用的图像文件类型。

JPEG，即“联合图像专家组”（Joint Photographic Experts Group）的缩写，以其高效的压缩能力而闻名。它非常适合照片和图像。然而，这种压缩是有损的，这意味着为了减小文件大小，图像质量会有所损失。

PNG（便携式网络图形）格式即使在压缩后也能保持图像质量，但这会导致文件体积较大。PNG 支持透明度，非常适合边缘锐利的图像，例如徽标和图标。

GIF图像格式支持动画和透明度，但颜色范围有限。GIF是“图形交换格式”（Graphics Interchange Format）的缩写。

最后，我们来看看SVG，它是“可缩放矢量图形”（Scalable Vector Graphics）的缩写。它是一种矢量图像格式。这种图像可以根据需要无限缩放而不会损失质量。

太好了。既然你已经了解了图像格式，接下来我们来看看视频和音频格式。

MP3 是一种以高效压缩著称的音频格式。它是一种有损压缩格式，因此在压缩过程中会丢失一些音频数据，从而减小文件大小。

MP4是最常见的视频格式之一。它具有良好的压缩性能，并支持多种音频和视频编解码器、字幕和元数据。

MOV 是苹果公司开发的 QuickTime 多媒体文件格式，主要与 QuickTime Player 相关联。

其他流行的音频和视频文件类型包括 WAV（一种无损音频格式，可保持音频的原始质量）和 WebM（一种高质量的开源视频格式）。

如果您需要自定义 Web 应用程序的字体，您也会用到字体格式。以下是三种最常用的字体格式。

TTF，即“TrueType字体”，是一种与不同操作系统兼容的字体格式。

WOFF 是一种专为网页开发而设计的现代字体格式，全称为“Web Open Font Format”（网络开放字体格式）。由于压缩率更高，这些文件体积更小，并且可以存储元数据，包括许可信息。

WOFF2 是 WOFF 的继任者，具有更高效的压缩和更优异的性能。

如果您需要将多个文件夹和文件分组，也可以创建压缩文件。最常用的压缩格式是 ZIP。ZIP 提供无损压缩，因此在压缩过程中不会丢失任何数据。它被广泛的操作系统和软件应用程序所支持。

最后，我们来谈谈文档。在 Web 应用程序中，通常会有一个名为 `.web` 的文件`README`，其中包含有关应用程序的信息，例如如何使用、如何安装、许可证以及如何贡献代码。

它们通常以 Markdown 文件格式编写。使用 Markdown，您可以创建包含标题、副标题、链接、图像、列表等的结构化文档。Markdown 文件具有 .markdown`.md`或 .markdown`.markdown`扩展名。

您可以在这里找到`README`freeCodeCamp GitHub 代码库的文件：https://github.com/freeCodeCamp/freeCodeCamp/blob/main/README.md

您可以使用 Markdown 创建这种详细的结构和格式。

在你的职业生涯中，你肯定会读写大量的`README`文件。了解这些常见的文件类型对于Web开发至关重要。

从 HTML、CSS 和 JavaScript 等核心构建模块到图像、视频和音频格式，每种文件类型在创建交互式 Web 应用程序方面都发挥着重要作用。

## 网络浏览器、网站和搜索引擎有什么区别？

网络浏览器是一种软件应用程序，使用户能够访问和浏览万维网。它们可以解释和显示网络内容，包括文本、图像、视频和交互元素。

网络浏览器的主要功能包括地址栏（用于输入网址或搜索查询）和渲染引擎（用于将 HTML、CSS 和 JavaScript 转换为可视网页）。

浏览器还提供书签功能，用于保存和整理喜爱的网站；提供扩展程序功能，用于增强浏览器功能；以及提供各种隐私和安全功能，例如弹出窗口拦截器和隐私浏览模式。

常用的网络浏览器包括谷歌浏览器、火狐浏览器、微软Edge浏览器、Safari浏览器和Opera浏览器。

另一方面，网站是由网页及其相关内容组成的集合，它们通过一个共同的域名进行标识，并发布在至少一台网络服务器上。它们是您使用网络浏览器访问的目标页面。

网站的组成部分包括域名（即网站的唯一地址，例如 freecodecamp.org）和网页（即构成网站的单个文档）。

网站通常还包含图像、视频和音频文件等多媒体内容，以增强用户体验，以及表单和按钮等交互元素，允许用户进行交互。

网站可以是静态的，内容很少改变；也可以是动态的，内容经常更新或根据用户进行个性化定制。

搜索引擎是基于网络的工具，旨在帮助用户在互联网上查找信息。它们使用复杂的算法，根据网页与用户查询的相关性对其进行索引和排名。

搜索引擎的关键方面包括网络爬虫（也称为蜘蛛或机器人），这些程序会系统地浏览网络以发现和索引新内容。

索引过程涉及将网页信息组织并存储在庞大的数据库中。

搜索引擎也采用排名算法，这是一种复杂的系统，它根据相关性、权威性和用户体验等因素来确定搜索结果的顺序。流行的搜索引擎包括谷歌、必应、雅虎和DuckDuckGo。

浏览器、网站和搜索引擎之间的关系是相互关联的。

网络浏览器是用来访问网站和搜索引擎的工具。

网站是用户通过浏览器访问或通过搜索引擎找到的目的地。

搜索引擎通过提供对网络上海量信息的有序访问，帮助用户发现网站。

理解这些区别和关系对于有效使用互联网和具备基本的网络素养至关重要。

## 如何有效使用搜索引擎以获得最佳搜索结果

在互联网上搜索信息可能是一项艰巨的任务。网站数量庞大，数据量也极其庞大，以至于找到想要的结果似乎是不可能的。

但得益于布尔搜索语法等功能，您可以将搜索范围缩小到您真正需要的内容。

布尔搜索语法是一种使用特殊词语来帮助您在网上搜索时准确找到所需内容的方法。

以下是一个基本搜索查询的示例`freecodecamp curriculum`。

当你搜索时`freecodecamp curriculum`，搜索引擎会返回与这些关键词匹配的结果_——_通常按相关性排序（它们与你的查询匹配或相关的可能性有多大）。

但如果您只想找到同时匹配这两个关键词的结果呢？您可能听说过，可以将查询语句用引号括起来，例如`"freecodecamp curriculum"`：

但是，此查询专门匹配_短语“_ `freecodecamp curriculum` together” 。这意味着您将看到的结果将仅限于包含“ `freecodecamp curriculum`together”的网站，而不是包含`freecodecamp`“AND”的网站`curriculum`。

如果您想匹配包含这两个词组的网站，但这两个词组不一定相邻出现，您可以像这样在每个词组前加上加号：`+freecodecamp +curriculum`

或者，您可能对 freeCodeCamp 课程之外的活动感兴趣。在这种情况下，您可以在该术语前加上`curriculum`减号，例如：`+freecodecamp -curriculum`。

这将返回包含“.”的结果`freecodecamp`，但排除也包含“.”的结果`curriculum`。

或者，您可能想搜索某个特定网站，例如我们的新闻平台？您可以使用`site:`后面跟上您要搜索的网站的 URL `site:freecodecamp.org/news curriculum`：。

此查询返回包含`freecodecamp.org/news`单词“.”的所有结果`curriculum`。

通过结合使用这些工具，您可以提出非常具体的查询，从而获得所需的确切信息。

例如，该查询`site:freecodecamp.org/news +python -curriculum`将在我们的新闻网站上搜索 Python 文章，但排除可能讨论我们课程的文章。

搜索运算符可能有所不同，因此务必查看您首选搜索引擎的文档。

但现在你应该能够通过网络搜索获得你想要的确切结果。
## HTTP 协议
### 请求

客户端发出的请求，主要由三个组成部分：请求行、请求头、请求主体
![[请求.png]]**1、请求行：**

- 请求方法：GET or POST
    
- 请求URL
    
- HTTP协议版本
    

**2、请求头：**

常见的请求头如下：

```
User-Agent：浏览器的具体类型　　如：User-Agent：Mozilla/5.0 (Windows NT 6.1; rv:17.0) Gecko/20100101 Firefox/17.0

Accept：浏览器支持哪些数据类型　　如：Accept: text/html,application/xhtml+xml,application/xml;q=0.9;

Accept-Charset：浏览器采用的是哪种编码　　如：Accept-Charset: ISO-8859-1

Accept-Encoding：浏览器支持解码的数据压缩格式　　如：Accept-Encoding: gzip, deflate

Accept-Language：浏览器的语言环境　　如：Accept-Language zh-cn,zh;q=0.8,en-us;q=0.5,en;q=0.3

Host：请求的主机名，允许多个域名同处一个IP地址，即虚拟主机。Host:www.baidu.com

Connection：表示是否需要持久连接。
属性值可以是Keep-Alive/close，HTTP1.1默认是持久连接，它可以利用持久连接的优点，当页面包含多个元素时（例如Applet，图片），显著地减少下载所需要的时间。
要实现这一点，Servlet需要在应答中发送一个Content-Length头，最简单的实现方法是：先把内容写入ByteArrayOutputStream，然后在正式写出内容之前计算它的大小。如：Connection: Keep-Alive

Content-Length：表示请求消息正文的长度。对于POST请求来说Content-Length必须出现。

Content-Type：WEB服务器告诉浏览器自己响应的对象的类型和字符集。例如：Content-Type: text/html; charset='gb2312'

Content-Encoding：WEB服务器表明自己使用了什么压缩方法（gzip，deflate）压缩响应中的对象。例如：Content-Encoding：gzip

Content-Language：WEB服务器告诉浏览器自己响应的对象的语言。

Cookie：最常用的请求头，浏览器每次都会将cookie发送到服务器上，允许服务器在客户端存储少量数据。

Referer：包含一个URL，用户从该URL代表的页面出发访问当前请求的页面。服务器能知道你是从哪个页面过来的。Referer: http://www.baidu.com/

```

**3、请求体：**

指的是提交给服务器的数据。

需要注意的是，如果是往服务器提交数据，需要在请求头中设置`Content-Type: application/x-www-form-urlencoded`(在ajax中需要手动设置)。

### 响应

响应报文是服务器返回给客户端的。组成部分有响应行、 头、响应主体。
![[响应.png]]
**1、状态行：**

HTTP响应行：主要是设置响应状态等信息。

**2、响应头：**

Cookie、缓存等信息就是在响应头的属性中设置的。

常见的响应头如下：

```
Cache-Control

响应输出到客户端后，服务端通过该报文头属告诉客户端如何控制响应内容的缓存。

下面，的设置让客户端对响应内容缓存3600秒，也即在3600秒内，如果客户再次访问该资源，直接从客户端的缓存中返回内容给客户，不要再从服务端获取（当然，这个功能是靠客户端实现的，服务端只是通过这个属性提示客户端“应该这么做”，做不做，还是决定于客户端，如果是自己宣称支持HTTP的客户端，则就应该这样实现）。

Cache-Control: max-age=3600

ETag

一个代表响应服务端资源（如页面）版本的报文头属性，如果某个服务端资源发生变化了，这个ETag就会相应发生变化。它是Cache-Control的有益补充，可以让客户端“更智能”地处理什么时候要从服务端取资源，什么时候可以直接从缓存中返回响应。

ETag: "737060cd8c284d8af7ad3082f209582d"

Location

我们在Asp.net中让页面Redirect到一个某个A页面中，其实是让客户端再发一个请求到A页面，这个需要Redirect到的A页面的URL，其实就是通过响应报文头的Location属性告知客户端的，如下的报文头属性，将使客户端redirect到iteye的首页中：

Location: http://www.google.com.hk

Set-Cookie

服务端可以设置客户端的Cookie，其原理就是通过这个响应报文头属性实现的。

Set-Cookie: UserID=JohnDoe; Max-Age=3600; Version=1


```

**3、HTTP响应体：**

如果请求的是HTML页面，那么返回的就是HTML代码。如果是JS就是JS代码。
