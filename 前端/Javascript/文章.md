# JavaScript入门
## 什么是 JavaScript？它如何与 HTML 和 CSS 协同工作？

JavaScript 是一种功能强大的编程语言，它能为网站带来交互性和动态行为。

HTML 和 CSS 是用于构建页面内容和设置页面元素样式的标记语言，而 JavaScript 则更进一步，能够实现更复杂的功能，例如处理用户输入、动画元素，甚至构建完整的 Web 应用程序。

例如，当您点击按钮、提交表单或将鼠标悬停在菜单上时，JavaScript 会决定页面的行为方式。

以下是这三者如何协同工作的一个例子：

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    h1 {
      color: green;
    }
  </style>
</head>
<body>
  <h1>Hello, World!</h1>
  <button onclick="alert('Button clicked!')">Click me</button>
</body>
</html>
```

在这个例子中，HTML 用于定义内容：标题（一个`h1`元素）和按钮（一个`button`元素）。

CSS 用于为标题应用样式，例如将文本设置为绿色。JavaScript 用于在按钮被点击时显示警告信息。

总而言之，HTML 提供结构，CSS 添加样式，JavaScript 实现行为，从而创造出完整且交互式的网络体验。

## 什么是字符串连接？如何将字符串与变量连接起来？

在 JavaScript 中，处理文本是编码的重要组成部分，而且经常需要将多段文本合并或连接在一起。这个过程称为字符串拼接。

在本课中，我们将重点学习字符串连接的工作原理，特别是使用`+`运算符、`+=`运算符和`concat()`方法。

该`+`运算符是连接字符串最简单、最常用的方法之一。它允许您连接多个字符串，或将字符串与存储文本的变量组合在一起。

举个例子：

```js

console.log(fullName); // John Doe
```

在这个例子中，我们使用`+`运算符将`firstName`​​ and`lastName`变量与空格 ( `" "`) 连接起来，创建了完整的名称。

使用`+`运算符进行字符串连接的一个缺点是，如果不仔细管理连接字符串之间的间距，可能会导致间距问题。

以下是一个缺少空格的例子：

```js

```

每当使用`+`连接运算符连接字符串时，务必仔细检查是否存在任何潜在的空格问题。

如果您需要向现有字符串添加或追加内容，可以使用该`+=`运算符。当您想要逐步添加更多文本来扩展字符串时，此方法非常有用。

# 理解代码清晰度
## 分号在 JavaScript 和编程中扮演什么角色？

在 JavaScript 和许多其他编程语言中，分号有助于分隔语句并提高代码可读性。

在 JavaScript 中，分号 ( `;`) 用于表示语句的结束。

就像句号 ( `.`) 表示英语句子的结束一样，分号表示可执行代码行的结束。这使得 JavaScript 引擎能够区分不同的命令。

例如：

```js
let variableOne = 5;  // Declare a variable and assign a value
let variableTwo = 10; // Declare another variable and assign a value
```

在这段代码中，每行末尾的分号标记了每个语句的结束。如果没有分号，JavaScript 引擎可能难以判断一个语句在哪里结束，另一个语句在哪里开始。

分号主要用于标记语句的结束。这有助于 JavaScript 引擎理解各个指令之间的分隔，这对正确执行至关重要。

```js
let a = 1;   // Statement ends here
let b = 2;   // Another statement starts here
```

虽然 JavaScript 具有自动分号插入 (ASI) 功能，可以自动添加分号，但显式地包含分号可以提高代码的清晰度，并有助于防止因 ASI 的意外行为而产生的错误。

分号在许多编程语言中都有使用，包括 C、C++ 和 Java。

分号用于标记语句或指令的结束，帮助编译器或解释器正确解析代码。编译器将高级编程语言代码翻译成机器可读代码，最终生成可执行文件。

分号通过清晰地划分语句，有助于提高代码的可读性和可维护性。分号有助于避免代码执行中的歧义，并确保语句正确终止。

分号是 JavaScript 和许多其他编程语言的基本组成部分。

它们标记语句的结束，提高代码可读性，并有助于避免与自动分号插入相关的错误。

# 数据类型
## JavaScript 中的动态类型是什么？它与静态类型语言有何不同？

JavaScript 是一种动态类型语言，这意味着你不需要在声明变量时指定其数据类型。相反，变量的类型会根据程序运行时分配给变量的值来确定。这使得你可以在程序运行过程中随时更改变量的类型。

我们来看一个例子：

```js
let example = "Hello";
example = 42;
```

在这个例子中，我们有一个名为 `value` 的变量，`example`其数据类型为字符串。但后来我们将 `value` 更新为数字类型。

动态类型的灵活性使 JavaScript 更易于容错和快速编写脚本，但它也可能引入一些更难发现的错误，尤其是在程序规模越来越大时。

在像 C# 或 C++ 这样的静态类型语言中，你必须在创建变量时声明其数据类型，并且该类型不能改变。

例如，如果您将一个变量声明为整数类型`integer`，则只能为其赋值整数值。如果您尝试为其赋值其他类型，程序将抛出错误。

以下是一个 C# 语言示例：

```csharp
int data = 42; // data must always be an integer
data = "Hello"; // This would cause an error in C#
```

动态类型和静态类型的区别在于代码的灵活性和安全性。动态类型语言提供了灵活性，但代价是可能出现运行时错误。

静态类型语言强制执行更严格的规则，可以防止某些错误，但它们需要更多的预先声明，并且在更改类型方面灵活性较低。

以下是创建变量并将`number`其类型更改为另一种类型的例子`string`：

```js
let data = 100;  // Initially a number
data = "New data";  // Dynamically changes to a string
```

在静态类型语言中，这种更改是不允许的，因为数据类型是固定的。

总之，JavaScript 的动态类型允许变量自由改变类型，这提供了灵活性，但也可能导致执行过程中出现意想不到的错误。

像 Java 这样的静态类型语言要求你预先指定变量类型，这有助于在程序运行之前捕获错误，但灵活性较差。

## 如何在字符串中创建换行符并转义字符串？

在 JavaScript 中处理字符串时，有时需要包含特殊字符，否则 JavaScript 引擎可能会错误地解释这些字符。

两个常见的任务包括在字符串中创建换行符和转义某些字符（如引号）以确保它们正确显示。

在许多编程语言（包括 JavaScript）中，可以使用称为转义序列的特殊字符在字符串中创建换行符。最常用的换行符转义序列是`\n`。

例如，如果您想将字符串分成多行，您可以使用`\n`新行的起始位置：

```js

```

转义`\n`序列告诉 JavaScript 在该位置插入换行符，从而使字符串显示在多行上。

处理字符串时，另一个重要的概念是转义字符。有时，你需要在字符串中包含一些 JavaScript 通常用于其他用途的字符，例如引号。

如果在字符串中直接使用引号而不进行转义，可能会导致错误，因为 JavaScript 会认为你是在试图结束字符串。

例如，这样做会导致错误：

```js

```

JavaScript 会感到困惑，因为它认为字符串在单词之后结束`"said,"`，但你希望引号周围的`"Hello!"`部分也成为字符串的一部分。

要解决这个问题，你可以在内部引号前加上反斜杠 ( `\`) 来转义它们：

```js
let statement = "She said, \"Hello!\"";
console.log(statement); // She said, "Hello!"
```

反斜杠告诉 JavaScript 将引号视为字面字符，以便它们在输出中正确显示。

您还可以转义其他特殊字符，例如反斜杠本身（\ `\\`），或者用单引号括起来的字符串中的单引号（`\'`\）。

以下是使用单引号的另一个例子：

```js

console.log(quote); // It's a beautiful day!
```

通过用反引号转义单引号`\'`，JavaScript 知道要将其包含在字符串中，而不是提前结束字符串。

在格式化输出或处理字符串中的特殊字符时，转义和换行符的使用至关重要。这些技巧有助于避免错误，并确保文本按预期显示。

## 什么是 ASCII，它如何与 charCodeAt() 和 fromCharCode() 一起使用？

在编程中，理解字符如何用数字表示至关重要。这就是 ASCII 的用武之地。ASCII，全称为美国信息交换标准代码（American Standard Code for Information Interchange），是一种用于计算机表示文本的字符编码标准。它为每个字符分配一个数值，这些数值可以被机器普遍识别。

ASCII 是一种将字母、数字和符号等字符编码为数值的系统。每个字符都对应一个特定的数字。

例如，在ASCII码中，大写字母`A`用数字表示`65`，小写字母`a`用数字表示`97`。这种编码方式使得计算机能够存储和处理文本。

ASCII 标准涵盖 128 个字符，其中包括：

- 大写和小写英文字母（AZ，az）。

## 运算符优先级是如何运作的？

如果你在 JavaScript 中编写一个包含多个运算符的表达式，JavaScript 如何决定先执行哪个运算符呢？这就是运算符优先级的作用所在。让我们通过代码示例详细探讨运算符优先级，以及当运算符优先级相同时会发生什么。

运算符优先级决定了表达式中运算的执行顺序。优先级较高的运算符会先于优先级较低的运算符执行。你可以把运算符优先级想象成数学运算，比如除法和乘法先于加法和减法。

如果不遵循这条规则，基本的方程式就会给出错误的答案。JavaScript 的工作方式也是如此。它有自己的一套规则，规定了运算符的先后顺序。例如，请看下面的表达式：

```js
const result = 2 + 3 * 4;

console.log(result); // 14
```

如果 JavaScript 从左到右计算这个表达式，你会期望得到 `a` `2 + 3 = 5`，然后是 ` `5 * 4 = 20`b`。但由于乘法的优先级高于加法，JavaScript 会`3 * 4`先计算乘法部分，结果为 `a` `2 + 12 = 14`。

有时，您可能希望表达式中的某些部分优先执行，而忽略优先级规则。您可以使用括号 `\ `()`` 来实现这一点。括号内的任何内容都会首先被计算，无论优先级规则如何。让我们让`2 + 3`上例中的 `\` 部分优先执行：

```js
const result = (2 + 3) * 4;

console.log(result); // 20
```

在上面的例子中，括号强制 JavaScript`2 + 3`先进行计算，然后将结果乘以`4`。这样得到的`20`是 而不是`14`。

除法运算符的优先级也高于加法或减法运算符：

```js
const result = 2 + 6 / 3;

console.log(result); // 4
```

如果 JavaScript 从左到右计算这个表达式，你可能会预期结果是 1/2 `2 + 6 = 8`，然后 2/3 `8 / 3 = 2.67`。但由于除法的优先级高于加法，JavaScript 会先计算除法：1/2 `6 / 3 = 2`，然后加上 2/3 `2 + 2`，得到结果 1/2 `4`。

因此，在乘法和除法运算中，除非使用括号改变顺序，否则这些运算总是会在加法和减法运算之前执行。那么，如果运算符的优先级相同会发生什么呢？JavaScript 使用结合律来确定运算顺序。

结合律决定了 JavaScript 计算运算符的顺序，是从左到右还是从右到左。对于大多数运算符（例如加法和乘法），结合律是从左到右。因此，JavaScript 会从表达式的最左侧开始向右侧处理这些运算符：

```js
const result = 10 - 2 + 3;

console.log(result); // 11
```

首先`10 - 2 = 8`，然后`8 + 3 = 11`。在这种情况下，JavaScript 从左到右执行操作。某些运算符，例如赋值运算符（`=`），是从右到左结合的。这意味着表达式的右侧会先被求值：

```js
let a, b;

console.log(a); // 5
console.log(b); // 5
console.log(a + b); // 10
```

在上面的例子中，JavaScript 首先将值赋给`5`，`b`然后将`b`（现在是`5`）的值赋给`a`。

指数运算符也具有从右到左的结合律：

```js

console.log(result); // 512
```

首先，JavaScript 会计算 `a+b `3 ** 2`+c`，结果等于 `a+b +c` `9`；然后，它会计算 `b+b +c` `2 ** 9`，结果等于 ` a+b+c` `512`。如果指数运算符具有从左到右的结合性，JavaScript 将会`2 ** 3`先计算 `a+b+c` 得到 `a+b +c` `8`，然后再`8 ** 2`计算`b+b+c` 得到 `a+b+c` `64`。
## 递增和递减运算符是如何工作的？

如果你正在处理数字，需要将某个值加一或减一，那么递增和递减运算符会让这项工作变得更轻松。让我们用简单的方式来解释一下。

递增运算符和递减运算符分别用`++`和表示`--`。它们都允许你通过 来调整变量的值`1`。

自增和自减运算符的工作方式有点特殊：它们有两种形式，前缀和后缀，区别在于值更新的时机。对于自增运算符，前缀是 `+`，`++x`后缀是 `-` `x++`。

前缀 ( `++x`) 先递增变量的值，然后返回新值。后缀 ( `x++`) 先返回变量的当前值，然后递增该值：

```js

console.log(x); // 6
```

在上面的代码中，` `++x`include` 表示“先递增`x`，然后使用它”。因此，当你记录 `include` 时`++x`，你会立即得到递增后的值，即 `include` `6`。

现在，让我们来看一个使用后缀的例子：

```js

console.log(y); // 6
```

在这个例子中，`y++``is` 的意思是“先使用`y`，然后递增”。当你记录 `is` 时`y++`，你会得到 `is` `5`，但在执行该行代码后，`is``y`就变成了`is`。`6`

递减运算符与递增运算符的功能相同，区别在于它将值减去指定的值`1`。递减运算符有两种形式：前缀运算符（`prefix` `--x`）先将变量的值减去指定的值，然后返回新的值；后缀运算符（`postfix` `x--`）先返回当前值，然后将其减去指定的值。


那么，应该使用前缀还是后缀呢？在很多情况下，使用哪个都无所谓，都能达到目的。但是，如果你要立即在表达式中使用值，那么区别就变得很重要了。我们来看一个例子：

```js
console.log(d); // 5 (c was incremented after assignment)
```

因此，如果您需要立即获取更新后的值，请使用前缀。如果您首先需要当前值，稍后才关心增量，请使用后缀。
## JavaScript 中的复合赋值运算符是什么？它们是如何工作的？

如您所见，`parseFloat()`程序从字符串开头开始解析，直到遇到不能作为浮点数一部分的字符为止。如果在字符串开头找不到有效的数字，则返回`NaN`“(不是数字)”。

`parseInt()`另一方面，`int` 会解析一个字符串参数并返回一个整数。与 `int` 类似`parseFloat()`，它从字符串的开头开始解析，但会在遇到第一个非数字字符时停止。以下是 `int` 的`parseInt()`工作原理：

`parseInt()`解析程序会在遇到第一个非数字字符时停止。对于浮点数，它只返回整数部分。如果在字符串开头找不到有效的整数，则返回空值`NaN`。

值得注意的是，虽然这些方法功能强大，但也存在一些局限性。例如，它们无法直接处理所有数字格式，例如科学计数法。对于更复杂的解析需求，您可能需要使用其他技术或库。

总之，` strings``parseFloat()`和 ` `parseInt()`numbers` 是 JavaScript 中将字符串转换为数字的实用工具。了解它们的工作原理和具体行为，可以帮助您在应用程序中更有效地处理数值数据，尤其是在处理用户输入或外部数据源时。

## 什么是 switch 语句？它们与 if/else 链有何不同？

`switch`语句和`if/else if/else`链都是编程中的控制流结构，允许我们根据特定条件执行不同的代码块。然而，它们具有不同的特性和应用场景。

语句`switch`会计算表达式的值，并将其与一系列`case`子句进行匹配。如果找到匹配项，`case`则执行与之关联的代码块。以下是语句的基本结构`switch`：

```js
switch (expression) {
  case value1:
    // code to be executed if expression === value1
    break;
  case value2:
    // code to be executed if expression === value2
    break;
  default:
    // code to be executed if expression doesn't match any case
}
```

`break`每个 switch 语句末尾的语句至关重要`case`。它告诉程序，一旦匹配的条件`case`被执行完毕，程序就应该退出 switch 代码块。如果没有这条语句，程序会继续执行后续的条件，这种行为被称为“向下传递”（fall-through）。

`switch`语句通常用于将单个变量与多个可能的值进行比较。当需要针对单个变量检查​​多个潜在条件时，语句尤其有用。以下示例使用`switch`语句来比较一周中的日期：

```js

    case 1:

        break;
    case 2:
        console.log("It's Tuesday! Keep the momentum going.");
        break;
    case 3:
        console.log("It's Wednesday! We're halfway there.");
        break;
    case 4:
        console.log("It's Thursday! Almost the weekend.");
        break;
    case 5:
        console.log("It's Friday! The weekend is near.");
        break;
    case 6:
        console.log("It's Saturday! Enjoy your weekend.");
        break;
    case 7:
        console.log("It's Sunday! Rest and recharge.");
        break;
    default:
        console.log("Invalid day! Please enter a number between 1 and 7.");
}
```

`switch`当处理单个变量的多个可能值时，语句可以更易读、更简洁。

`if/else if`另一方面，条件语句更加灵活。它们可以评估复杂的条件，并且每个子句中可以包含不同的变量。这使得它们适用于更广泛的场景。以下是一个可能使用条件`if/else`语句而非`switch`条件语句的示例：

# 函数

## 函数的作用是什么？它们是如何工作的？

函数是可重用的代码片段，用于执行特定任务或计算值。可以将函数想象成一台机器，它接收输入，对其进行一些操作，然后产生输出。以下是一个声明函数的示例：

```js
function greet() {
  console.log("Hello, Jessica!");
}
```

在这个例子中，我们声明了一个名为 `log()` 的函数`greet`。在该函数内部，我们有一个`console.log``log()` 语句来记录消息`Hello, Jessica!`。如果我们尝试运行这段代码，不会在控制台中看到消息。这是因为我们需要调用 `log()` 函数。

函数调用，或称函数执行，是指实际使用或执行函数的过程。要调用函数，需要引用函数名，并在其后加上一对括号：

```js
function greet() {
  console.log("Hello, Jessica!");
}

greet(); // "Hello, Jessica!"
```

现在，消息`Hello, Jessica!`将被记录到控制台。但如果我们想让消息显示为“是”`Hello, Nick!`或“否”呢`Hello, Anna!`？我们不想每次问候不同用户时都编写一个新函数。相反，我们可以创建一个可重用的函数，该函数使用函数参数和实参。

参数充当占位符，用于存储调用函数时将要传递的值。它们允许函数接受输入并处理这些输入。实参是调用函数时实际传递的值。以下是`greet`使用参数和实参的函数更新版本：

```js
function greet(name) {
  console.log("Hello, " + name + "!");
}

greet("Alice"); // Hello, Alice!
greet("Nick"); // Hello, Nick!
```

用作`name`参数，而字符串`Alice`和`Nick`用作实参。现在我们有了一个可重用的函数，可以在代码中多次使用，并传入不同的参数。

函数执行完毕后，总会返回一个值。默认情况下，返回值为空`undefined`。以下是一个示例：

```js
function doSomething() {
  console.log("Doing something...");
}

let result = doSomething();
console.log(result); // undefined
```

如果您的函数需要返回特定值，则需要使用 ` `return`INSERT` 语句。以下示例展示了如何使用 ` `return`INSERT` 语句返回两个值的和：

```js
function calculateSum(num1, num2) {
  return num1 + num2;
}

console.log(calculateSum(3, 4)); // 7
```

很多时候你会用到这个`return`语句，因为你可以在代码的后面部分使用函数输出的值。

到目前为止，我们一直在使用命名函数，但你还可以创建所谓的匿名函数。匿名函数是一个没有名称的函数，可以像这样将其赋值给一个变量：

```js
const sum = function (num1, num2) {
  return num1 + num2;
};

console.log(sum(3, 4)); // 7
```

在这个例子中，我们有一个`const`名为 `sum` 的变量`sum`，我们给它赋了一个匿名函数，该函数返回 `a` 和 ` b` 的`num1`和`num2`。然后我们可以调用该函数`sum`，并传入数字 `a``3`和 `b``4`来获取 `sum` 的结果`7`。

函数支持默认参数，允许您为参数设置默认值。如果在调用函数时未为某个参数提供实参，则会使用这些默认值。例如：

```js
function greetings(name = "Guest") {
  console.log("Hello, " + name + "!");
}

greetings(); // Hello, Guest!
greetings("Anna"); // Hello, Anna!
```

在这个例子中，如果没有为提供参数`name`，则默认值为`Guest`。

总而言之，函数使你能够编写可重用且结构清晰的代码。它们可以接收输入（参数）、执行操作并返回输出。

## 什么是箭头函数，它们是如何工作的？

## 编程中的作用域是什么？全局作用域、局部作用域和块作用域是如何工作的？

在编程中，作用域指的是变量在代码不同部分的可见性和可访问性。它决定了变量可以在哪些地方被访问或修改。在 JavaScript 中，理解作用域对于编写简洁、高效且无 bug 的代码至关重要。作用域主要分为三种类型：全局作用域、局部作用域和代码块作用域。

全局作用域是 JavaScript 程序中最外层的作用域。在全局作用域中声明的变量可以从代码中的任何位置访问，包括函数和代码块内部。这些变量通常被称为全局变量。虽然全局变量很方便，但应该谨慎使用，因为它们可能会导致命名冲突，并使代码更难维护。以下是一个全局变量的示例：

```js
function greet() {
```

全局变量应谨慎使用，因为它们容易导致命名冲突，使代码更难维护。局部变量有助于隔离代码的不同部分，这在大型程序中尤为重要。使用块级作用域`let`可以`const`更精细地控制变量的访问，有助于防止错误并使代码更可预测。掌握全局作用域、局部作用域和块级作用域这些基本概念，将为理解更高级的主题奠定坚实的基础。

## 如何使用字符串和数组方法反转字符串？

## 什么是数组的浅拷贝？创建这些拷贝的方法有哪些？

数组的浅拷贝是指创建一个与原数组包含相同元素的新数组。如果原数组只包含数字或字符串等基本类型值，则新数组与原数组完全独立。但如果原数组内部包含其他数组，则原数组和拷贝数组都引用了相同的内部数组。这意味着，如果您更改了共享的内部数组中的某些内容，则两个数组都会发生同样的更改。

当您需要修改顶层结构（例如添加、删除或重新排列元素）而不修改原始数组或内部数组时，浅拷贝非常有用。

我们先来看这个`concat()`方法。这个方法通过合并两个或多个数组来创建一个新数组。当用于单个数组时，它实际上创建的是浅拷贝。以下是一个示例：

```js

console.log(copyArray === originalArray); // false
```

在这个例子中，我们使用该`concat()`方法将一个空数组连接到数组中`originalArray`。这将创建一个新数组，它是原数组的浅拷贝`originalArray`。

它`copyArray`包含与相同的元素`originalArray`，但它是一个不同的数组对象，这就是为什么严格相等性检查（`===`）返回的原因`false`。

创建浅拷贝的另一种方法是使用 `slowcopy``slice()`方法。当不带参数调用时，该方法`slice()`返回整个数组的浅拷贝。其工作原理如下：

```js

console.log(copyArray); // [1, 2, 3]
console.log(copyArray === originalArray); // false
```

在这种情况下，`originalArray.slice()`它会创建一个新数组，该数组是原数组的浅拷贝`originalArray`。同样，新数组`copyArray`包含相同的元素，但它是一个不同的数组对象。

`...`ES6 中引入的扩展运算符 ( ) 提供了一种简洁的方式来创建数组的浅拷贝。以下是一个示例：

展开运算符 ( `...`) 将数组元素展开`originalArray`到一个新数组中，实际上创建了一个浅拷贝。需要注意的是，所有这些方法都会创建新的数组对象，这意味着您可以修改副本而不会影响原始数组。例如：

总之，可以使用诸如`concat()``__new__`、`slice()``__new__` 或扩展运算符等方法轻松创建数组的浅拷贝。这些方法对于创建可以独立于原始数组进行操作的新数组非常有用。

## 原始数据类型和非原始数据类型有什么区别？

在 JavaScript 中，理解原始数据类型和非原始数据类型之间的区别对于编写高效且无错误的代码至关重要。

这两种数据类型在内存中的存储方式以及在程序中的操作方式方面表现不同。

原始数据类型是 JavaScript 中最简单的数据形式。它们包括数字、字符串、布尔值、整数`null`、`undefined`字符串和符号。这些类型之所以被称为“原始”，是因为它们表示单个值，而不是对象。

使用基本数据类型时，您直接操作的是它们的值。例如，当您创建一个具有基本值的变量时，该值将直接存储在该变量中。

原始值是不可变的，这意味着一旦创建，其值就无法更改。但是，您可以为变量重新赋值。以下是使用原始数据类型的示例：

```js
let num1 = 5;
let num2 = num1;
num1 = 10;

console.log(num2); // 5
```

在这个例子中，我们将原始值（`5`）从`num1`原变量赋值`num2`给新变量。这会创建一个独立的副本。因此，对原变量（`num1`）所做的任何更改都不会影响副本（`num2`）。

另一方面，非原始数据类型则更为复杂。在 JavaScript 中，这些数据类型包括对象（例如普通对象、数组和函数）。与原始数据类型不同，非原始数据类型可以存储多个值作为属性或元素。

当你创建一个具有非原始类型值的变量时，变量中实际存储的是对象在内存中的存储位置的引用，而不是对象本身。这会导致一些重要的行为差异。以下是一个使用非原始类型的示例：

```js
const originalPerson = { name: "John", age: 30 };
const copiedPerson = originalPerson;

originalPerson.age = 31;

console.log(copiedPerson.age); // 31
```

在这个例子中，我们有一个名为 `object` 的对象，`originalPerson`它有两个属性 `a``name`和 `b` `age`。然后我们将该`originalPerson`对象赋值给一个名为 `variable` 的变量`copiedPerson`。

然后我们更新对象`age`的值`originalPerson`。当我们记录对象`age`的属性时`copiedPerson`，它会显示更新后的值。

但为什么会这样呢？这是因为两者`originalPerson`都`copiedPerson`引用了内存中的同一个对象。

在 JavaScript 中，当你将一个对象赋值给另一个变量时，你复制的是对该对象的引用，而不是对象本身。这被称为按引用浅拷贝。因此，通过一个引用对对象所做的任何更改都会反映到所有指向该对象的引用中。

随着你不断学习 JavaScript，你会遇到很多需要理解基本类型和非基本类型之间区别的情况。这是一个基础概念，贯穿于 JavaScript 的许多方面，也是编写高效且正确代码的关键。
## 函数和对象方法有什么区别？

在 JavaScript 中，函数和对象方法都是封装可重用代码的方式，但它们在定义、使用和运行上下文方面存在一些关键差异。理解这些差异对于编写高效且结构清晰的 JavaScript 代码至关重要。

正如你在前面的模块中所学到的，函数是可重用的代码块，用于执行特定任务：

```js

    return "Hello, " + name + "!";
}
console.log(greet("Alice")); // "Hello, Alice!"
```

另一方面，对象方法是与对象关联的函数。它们被定义为对象的属性，可以访问和操作对象的数据。以下是一个带有方法的对象示例：

```js

    name: "Bob",
    age: 30,
    sayHello: function() {
        return "Hello, my name is " + this.name;
    }
};

console.log(person.sayHello()); // "Hello, my name is Bob"
```

在这个例子中，` `sayHello`is` 是对象的一个​​方法`person`。`keyword``this`关键字允许该`sayHello`方法访问名为 `is` 的对象的属性`person`。你将`this`在后续课程中学习更多关于 `keyword` 关键字的内容。

函数和方法的区别在于它们的调用方式。函数通过其名称调用，而方法则使用点号表示法调用其所属的对象。例如，我们调用函数`greet`为 `f(function) `greet("Alice")``，而调用`sayHello`方法为 `method.get(method) `person.sayHello()``。

另一个重要的区别在于它们的运行上下文。普通函数有自己的作用域，但它们没有对任何特定对象的内置引用。而方法则绑定到其所属对象，并且可以使用`this`关键字访问该对象的属性和其他方法。

需要注意的关键一点是，方法有助于将代码组织成逻辑对象，而函数则用于更通用、可重用的代码。

在 JavaScript 学习过程中，理解函数和对象方法之间的区别至关重要。虽然它们乍看之下可能很相似，但了解何时使用哪种方法将有助于你编写更条理清晰、高效且更优质的代码。

## 什么是 JSON？如何使用括号和点号表示法访问值？

什么是 JSON？如何使用括号和点号表示法访问值？

JSON 是 JavaScript 对象表示法的缩写。它是一种轻量级的、基于文本的数据格式，常用于服务器和 Web 应用程序之间交换数据。

JSON 在 Web 开发中如此流行的原因之一是它既可以被机器解析，又可以被人类阅读。

由于 JSON 与语言无关，您可以轻松地将 JSON 数据从 Java 应用程序发送到 Python 应用程序，或者从 JavaScript 应用程序发送到 C# 应用程序。

JSON 支持多种数据类型，包括对象、数组、字符串、布尔值、null 和数字。

以下是一个 JSON 对象示例：

```js
{
  "name": "Alice",
  "age": 30,
  "isStudent": false,
  "list of courses": ["Mathematics", "Physics", "Computer Science"]
}
```

如您所见，JSON 使用键值对来存储信息，每对键值之间用逗号分隔。每个键都必须用双引号括起来，否则会出错。

要访问 JSON 对象中的数据，可以使用点号或方括号表示法。在本例中，我们使用点号表示法来访问`age`JSON 对象中的数据：

```js
import data from "./example.json" with { type: "json" };

console.log(data.age);
```

这个例子使用了所谓的`import`语句，它将 JSON 对象导入到这个文件中，以便我们能够访问它。你将`import`在以后的课程中学习更多关于语句的内容。

您还可以使用方括号表示法来访问 JSON 对象中的信息。以下是访问数组的示例`list of courses`：

```js
import data from "./example.json" with { type: "json" };

console.log(data["list of courses"]);
```

这里使用方括号表示法特别有用，因为密钥包含多个以空格分隔的单词。如果我们尝试使用点表示法，则会导致错误。

总而言之，JSON 是一种用途广泛的格式，可以存储多种数据类型，包括数组和嵌套对象。通过使用点号或方括号表示法，您可以轻松访问 JSON 对象中存储的值。
