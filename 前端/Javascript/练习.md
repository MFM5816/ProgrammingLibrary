# 构建一个问候机器人

 
 - 步骤 3

在之前的课程中，你学习了`let`关键字以及如何在 JavaScript 中声明变量。

以下是如何使用关键字声明变量的简要说明`let`：

示例代码

```js
let greeting;
```

使用`let`关键字声明一个名为`bot`.

**注意**：您在`let`此处使用该变量是因为稍后在研讨会中，您将更改该`bot`变量的值。


 - 第四步

现在，是时候给`bot`变量赋值了。

在之前的课程中，你学习了如何像这样给变量赋值：

示例代码

```js
variableName = "Here is the value";
```

请记住，赋值运算符右侧的值`=`就是你要赋给左侧变量的值。

将字符串赋值`"teacherBot"`给`bot`变量。

- 第五步

现在，是时候初始化`botLocation`变量了。

当需要用多个单词声明变量时，可以使用驼峰命名法。

以下是一个例子：

示例代码

